# 0.9.5

A 股自选与持仓的轻量盯盘插件，装在右侧面板里，一眼看完全部自选。

## 这一版

- **列表可拖动排序**：自选与持仓都能按住行上下拖动，卡片与表格通用，落点有插入线，松手即记住；「设置 › 排序」选「按涨跌幅 / 按代码」时自动停用拖动。
- **提示不再打扰**：改成面板底部的浮层气泡，不占布局、不把内容顶下去、不挡顶部按钮；刷新、改设置、切视图这类操作不再弹提示，只在页脚更新状态。
- **出错才提醒**：宿主回执只在失败时提示，同一条错误 60 秒内只弹一次；重复添加同一只股票会直接给出提示。

## 功能

- 卡片 / 表格双视图，10 个可选列自由勾选，表头拖动调整顺序，代码与名称固定在左侧、操作列固定在右侧
- 日内区间条标出当前价在当日振幅里的位置，持仓者还能看到成本线
- 持仓弹窗：填成本与数量，实时算市值与浮动盈亏，Enter 保存
- 20 项偏好：涨跌配色（红涨绿跌 / 跟随习惯）、隐匿模式、密度、字号、小数位、刷新间隔、排序方式、安静时段
- 删除自选二次确认；行情失败静默重试，不刷屏

## 安装

`Settings › Plugins › Install from Disk`，选 `jiusi.stock-watch-0.9.5.oiplugin`。

## 权限

- `storage`：自选、持仓与偏好只存在本机
- `net:push2.eastmoney.com`：拉取行情，仅此一个域名

不收集任何数据，没有账号，没有后端。
