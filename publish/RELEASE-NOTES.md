# 0.9.6

A 股自选与持仓的轻量盯盘插件，装在右侧面板里，一眼看完全部自选。

## 这一版

- **行情换到腾讯财经**：原来走东方财富的批量接口，它要先回一个 302 再跳转，两跳加起来 4–7 秒，而宿主给单次调用只留 5 秒——插件因此被判超时、反复重启。腾讯接口一次请求 0.2–0.3 秒返回全部报价，没有跳转。
- **图标补齐**：插件列表里有了自己的图标（明暗两套，随主题切换），右侧边栏的视图也有专属图标——单独画了 16px 的精简版，不靠缩小大图硬凑。
- **输入框更干净**：成本价、持仓数量去掉了 WebView 自带的上下微调箭头，只保留直接键入。

## 修复

- 安装静默失败：图标 SVG 里写了 `role="img"`，而宿主对插件图标走严格白名单校验，属性表里没有 `role`，导致整个包校验在弹窗之前就失败——表现是点了「从插件包安装」没有任何反应。已移除该属性。
- 请求加了 4 秒兜底超时，接口卡住时先自己放弃并提示，不再拖到宿主强杀整个插件。

## 功能

- 卡片 / 表格双视图，10 个可选列自由勾选，表头拖动调整顺序；列表行也能按住拖动排序
- 日内区间条标出当前价在当日振幅里的位置，持仓者还能看到成本线
- 持仓弹窗：填成本与数量，实时算市值与浮动盈亏，Enter 保存
- 20 项偏好：涨跌配色（红涨绿跌 / 跟随习惯）、隐匿模式、密度、字号、小数位、刷新间隔、排序方式、安静时段
- 删除自选二次确认；同一条错误 60 秒内只提示一次

## 安装

`Settings › Plugins › Install from Plugins Package`，选 `jiusi.stock-watch-0.9.6.oiplugin`。

## 权限

- `storage`：自选、持仓与偏好只存在本机
- `net:qt.gtimg.cn`：拉取行情，仅此一个域名（响应为 GBK，插件本地解码）

不收集任何数据，没有账号，没有后端。
